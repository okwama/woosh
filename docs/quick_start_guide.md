# Quick Start Guide

## Welcome to Woosh! 🚀

This guide will help you get started with the Woosh field sales management application in just a few minutes. Follow these steps to begin managing your clients, journey plans, orders, and sales efficiently.

## 📱 First Time Setup

### 1. Download and Install
- **Android**: Download from Google Play Store
- **iOS**: Download from Apple App Store  
- **Web**: Access via web browser at [your-woosh-url]
- **Desktop**: Download desktop application

### 2. Account Creation
1. Launch the Woosh application
2. Tap **"Sign Up"** on the login screen
3. Fill in your information:
   - Full Name
   - Email Address
   - Phone Number
   - Employee ID (if provided)
   - Create a secure password
4. Complete email verification if required
5. Grant necessary permissions (location, camera, storage)

### 3. Initial Setup
- Complete your profile information
- Set up your preferences
- Allow the app to sync initial data
- Take the optional app tour to learn key features

## 🎯 Quick Tour: Essential Features

### 🏠 Home Dashboard
Your central hub for daily activities:
- **Today's Schedule** - View planned journey and visits
- **Quick Actions** - Fast access to common tasks
- **Performance Summary** - Daily/weekly statistics
- **Notifications** - Important updates and reminders

### 🗺️ Journey Planning (Your Daily Route)
Plan and execute your client visits:

**Create a Journey Plan:**
1. Tap **"Journey Plans"** from the main menu
2. Select **"Create New Journey"**
3. Choose your visit date and start time
4. Add clients to visit (tap **"Add Clients"**)
5. Review the optimized route
6. Save your journey plan

**Execute Your Journey:**
1. Start your journey when ready to begin
2. Navigate to each client using built-in GPS
3. Check in when you arrive at each location
4. Complete your visit activities
5. Check out and add visit notes
6. Continue to the next client

### 👥 Client Management
Manage your customer relationships:

**Add a New Client:**
1. Go to **"Clients"** → **"Add Client"**
2. Enter business information (name, address, contact)
3. Set up financial details (credit limit, payment terms)
4. Save the client profile

**Visit a Client:**
1. Search for the client in your database
2. View their profile and history
3. Add them to a journey plan or start an immediate visit
4. Document your interaction and outcomes

### 📦 Order Management
Process customer orders efficiently:

**Create an Order:**
1. Navigate to **"Orders"** → **"New Order"**
2. Select the client for this order
3. Browse products and add to cart
4. Review quantities and pricing
5. Confirm order details and submit

**Track Orders:**
- View all orders in **"Order History"**
- Check order status and delivery information
- Communicate updates to clients

### 💰 Point of Sale (Uplift Sales)
Process immediate sales transactions:

**Make an Uplift Sale:**
1. Go to **"POS"** → **"Uplift Sales"**
2. Select products for immediate sale
3. Choose the client or enter new client details
4. Process payment (cash, card, or digital)
5. Generate and deliver receipt

## 🚨 Common First-Week Scenarios

### Scenario 1: Planning Your First Journey
```
Goal: Create a route to visit 3 clients tomorrow

Steps:
1. Open Journey Plans → Create New Journey
2. Set tomorrow's date and start time (e.g., 9:00 AM)
3. Add Client A (priority visit)
4. Add Client B (follow-up needed)
5. Add Client C (new prospect)
6. Review optimized route and estimated times
7. Save journey plan
8. Set reminder for tomorrow morning
```

### Scenario 2: Recording Your First Client Visit
```
Goal: Document a successful client meeting

Steps:
1. Start your journey plan for the day
2. Navigate to first client location
3. Check in when you arrive (GPS automatic or manual)
4. During visit: Take notes on discussion points
5. After visit: Check out and complete visit summary
6. Add follow-up actions if needed
7. Continue to next client
```

### Scenario 3: Processing Your First Order
```
Goal: Create an order for a client during a visit

Steps:
1. During client visit, discuss product needs
2. Open Orders → New Order
3. Select current client
4. Browse products and add items to cart
5. Adjust quantities based on client needs
6. Apply any applicable discounts
7. Review order total with client
8. Submit order for processing
9. Provide order confirmation to client
```

### Scenario 4: Making Your First Uplift Sale
```
Goal: Process an immediate sale transaction

Steps:
1. Client wants to purchase products immediately
2. Go to POS → Uplift Sales
3. Add products to uplift cart
4. Verify stock availability
5. Calculate total including taxes
6. Process payment (cash/card/digital)
7. Generate receipt for client
8. Update inventory automatically
```
